# 水产养殖管理系统 - 规格说明

## 1. 项目概述

本项目是一个水产养殖管理系统，包含水质监测、养殖记录管理、疾病防控和溯源管理等功能模块。本次迭代主要针对以下三个方面进行改进：

1. **历史数据折叠列表**：将水质监测的历史数据表格改为可折叠的时间线列表，改善大量数据的展示体验
2. **养殖记录管理问题修复**：修复点击苗种投放、饲料投喂、捕捞记录时出现的问题
3. **溯源管理功能完善**：实现完整的鱼苗批次溯源体系，从苗种投入到捕捞全过程记录，并生成对应的溯源二维码

## 2. 功能规格

### 2.1 历史数据折叠列表

#### 2.1.1 需求描述
当前水质监测页面的历史数据以表格形式全部展开显示，当数据量较大时页面冗长。需要改为可折叠的时间线列表形式。

#### 2.1.2 实现方案
- 将历史数据表格替换为折叠面板（Collapse）组件
- 按日期分组（同一天产生的水质数据归为一组）
- 每组默认折叠，点击可展开查看该日所有记录
- 每组标题显示：日期、记录数量、该日数据概览（平均水温、最高/最低值等）
- 展开后以表格形式显示该日所有记录
- 保留现有的表格样式和深色主题

#### 2.1.3 技术实现
- 前端：使用 Element Plus 的 `el-collapse` 组件
- 数据分组逻辑：在 Vue 组件中对 waterQualityList 按日期进行分组
- 每组统计信息：计算平均值、最大值、最小值

### 2.2 养殖记录管理问题修复

#### 2.2.1 问题描述
当前养殖记录管理（AquacultureRecord.vue）存在以下问题：
1.  ResizeObserver 运行时错误
2.  添加记录时缺少 zoneId 关联，导致数据无法正确关联到养殖区域
3.  苗种投放记录缺少批次号字段，无法与溯源系统关联
4.  记录列表没有按时间排序
5.  表格列宽和内容展示不够完善

#### 2.2.2 实现方案
1. **ResizeObserver 错误修复**：确保组件在挂载时正确初始化，避免重复初始化
2. **zoneId 关联**：确保所有添加记录的操作都正确传递 zoneId
3. **苗种批次号**：在苗种投放记录中增加 batchNo 字段，用于溯源关联
4. **排序**：记录列表按时间倒序排列（最新记录在前）
5. **表格优化**：完善表格列展示，增加备注列，优化列宽

#### 2.2.3 技术实现
- 后端：SeedlingRecord 实体增加 batchNo 字段，更新数据库表结构
- 后端：在 SeedlingRecordController 和 Service 中支持 batchNo
- 前端：AquacultureRecord.vue 增加 batchNo 输入和显示
- 前端：确保 zoneId prop 正确传递和使用
- 前端：修复 ResizeObserver 问题，使用 nextTick 确保 DOM 更新

### 2.3 溯源管理功能完善

#### 2.3.1 需求描述
当前溯源管理系统功能不完善：
1. 溯源码生成与养殖记录脱节
2. 溯源信息查询仅显示基本信息，无完整链路
3. 缺少溯源二维码生成功能
4. 缺少独立的溯源展示页面（扫码/访问链接时展示）

需要实现：
- 每个苗种批次投入养殖后，自动/手动生成溯源码
- 溯源码关联该批次的所有操作记录：苗种投放、饲料投喂、疾病治疗、水质数据、捕捞
- 生成溯源二维码
- 提供独立的溯源展示页面，扫描或访问链接时展示完整溯源信息

#### 2.3.2 实现方案

**数据模型改进**：
- TraceabilityCode 实体增加 batchNo（关联苗种批次）、zoneId（关联养殖区域）、qrCodeUrl（二维码URL）字段
- 溯源码与苗种批次号一对一关联

**后端实现**：
1. 新增批量生成溯源码接口：根据苗种批次号生成溯源码
2. 新增二维码生成接口：使用 ZXing 库生成溯源二维码图片
3. 完善 getTraceabilityInfo 接口：返回完整的溯源链路数据
4. 新增独立溯源展示接口：返回 HTML 页面用于扫码展示

**前端实现**：
1. TraceManage.vue 改造：
   - 新增批次选择（下拉选择已有的苗种批次）
   - 选择批次后点击生成溯源码
   - 生成后显示二维码（前端使用 qrcode.vue 库渲染）
   - 显示该批次的溯源信息时间线
2. 新增 TraceabilityPublic.vue 页面：
   - 独立的公开溯源展示页面（路由：/traceability/:code）
   - 按时间线展示从苗种投入到捕捞的全过程
   - 包含：苗种信息、养殖区域、饲料投喂记录、疾病防治记录、水质变化趋势、捕捞信息
   - 无需登录即可访问

#### 2.3.3 溯源链路设计
```
苗种投放（含批次号）
    ↓
饲料投喂（关联区域）
    ↓
疾病治疗（关联区域）
    ↓
水质监测（关联区域）
    ↓
捕捞记录（关联区域和苗种批次）
    ↓
生成溯源码（关联捕捞记录或苗种批次）
    ↓
生成二维码 → 扫码/访问链接 → 展示完整溯源时间线
```

## 3. 技术规格

### 3.1 后端技术栈
- Spring Boot 3.x
- MyBatis Plus
- SQLite (marine_aquaculture.db)
- ZXing (二维码生成)

### 3.2 前端技术栈
- Vue 3
- Element Plus
- ECharts (图表)
- qrcode.vue (二维码生成)

### 3.3 API 设计

#### 溯源相关新增/修改 API
| 方法 | 路径 | 描述 |
|------|------|------|
| POST | /api/traceability/batch/{batchNo} | 根据苗种批次号生成溯源码 |
| GET | /api/traceability/qrcode/{code} | 获取溯源二维码（返回图片） |
| GET | /api/traceability/public/{code} | 获取公开溯源信息（返回JSON） |
| GET | /api/seedlings/batches | 获取所有苗种批次列表 |
