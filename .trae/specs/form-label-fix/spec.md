# 表单标签文字显示问题修复 - 产品需求文档

## 概述
- **Summary**: 修复水产养殖管理系统中点击"添加记录"或"记录病害"按钮时，表单左侧标签文字不显示的问题
- **Purpose**: 解决 Element Plus 对话框（Dialog）中表单标签文字不可见的样式问题，确保用户能够正常填写表单
- **Target Users**: 所有使用水产养殖管理系统的用户

## 问题分析
经过代码审查，发现问题根源：
1. Element Plus 的 Dialog 组件使用 Teleport 将内容挂载到 body 下，导致 scoped 样式无法应用
2. 虽然已有非 scoped 样式，但样式选择器可能不够精确或被默认样式覆盖
3. 表单标签颜色可能与背景颜色对比度不足或被隐藏

## 目标
1. 修复 DiseaseControl.vue 中记录病害对话框的标签文字显示问题
2. 修复 AquacultureRecord.vue 中三个添加记录对话框的标签文字显示问题
3. 确保对话框中的所有表单元素都能正确显示在深色主题下

## 非目标
- 不修改其他组件的功能逻辑
- 不改变表单的功能和布局结构
- 不修改后端 API

## 背景和上下文
项目使用 Vue 3 + Element Plus，采用深色主题设计。对话框组件通过 Teleport 渲染，需要特殊处理样式。

## 功能要求
- **FR-1**: 病害防控对话框的所有表单标签必须清晰可见
- **FR-2**: 养殖记录的三个对话框（苗种投放、饲料投喂、捕捞记录）的表单标签必须清晰可见
- **FR-3**: 对话框整体保持一致的深色主题风格

## 非功能要求
- **NFR-1**: 样式解决方案必须可维护，避免代码重复
- **NFR-2**: 确保在不同屏幕尺寸下都能正常显示
- **NFR-3**: 性能不受影响，样式加载速度快

## 约束条件
- **技术**: 必须使用现有的 Element Plus 2.3.14 和 Vue 3 框架
- **依赖**: 不能引入新的第三方库
- **兼容性**: 需要保持与现有代码结构兼容

## 假设
- Element Plus 组件的 DOM 结构在当前版本中保持稳定
- 浏览器的 CSS 支持正常
- 深色主题的配色方案是固定的

## 验收标准

### AC-1: 病害防控对话框标签可见
- **Given**: 用户点击"记录病害"按钮
- **When**: 对话框打开
- **Then**: "病害名称"、"发生日期"、"症状"、"处理措施"标签必须清晰可见，颜色为白色或浅色
- **Verification**: human-judgment
- **Notes**: 标签文字必须清晰可读，对比度足够

### AC-2: 苗种投放对话框标签可见
- **Given**: 用户选择养殖区域后点击"添加记录"
- **When**: 对话框打开
- **Then**: 所有表单标签必须清晰可见
- **Verification**: human-judgment

### AC-3: 饲料投喂对话框标签可见
- **Given**: 用户选择养殖区域后点击"添加记录"
- **When**: 对话框打开
- **Then**: 所有表单标签必须清晰可见
- **Verification**: human-judgment

### AC-4: 捕捞记录对话框标签可见
- **Given**: 用户选择养殖区域后点击"添加记录"
- **When**: 对话框打开
- **Then**: 所有表单标签必须清晰可见
- **Verification**: human-judgment

### AC-5: 对话框样式一致性
- **Given**: 任意对话框打开
- **When**: 查看界面
- **Then**: 对话框整体风格与现有深色主题保持一致
- **Verification**: human-judgment
